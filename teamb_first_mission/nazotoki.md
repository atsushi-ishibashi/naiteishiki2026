迷路4枚を作り、企画詳細として書き直しました。コードでの自動検証はできないので、4本のルートの重なりを手で数え直し、各迷路の分岐も1本ずつたどって確認しています。印刷前に、4枚を実際に解いてみてください。

作る過程で決めたことは3つです。

- **ゲートの位置**: Ⅰ=左上、Ⅱ=左辺、Ⅲ=下辺、Ⅳ・Ⅴ=右辺にしました。5つとも全カードで開口させたので、順番を間違えても迷路は解けてしまい、5マスが揃わないことで気づく設計です。
- **共通マスの位置**: 5マスをゲート付近に寄せました。4本の経路を必ず通らせるためです。
- **確認できていない事実**: 歴史の順序と登録日は、元のAI案の記述のままです。公式情報での確認が必要なので、チェックリストに入れました。

以下がそのまま使えるmdです。

# Team B「4つのサービス、1つの正体」企画詳細

## 1. 企画の概要

| 項目 | 内容 |
|---|---|
| 対象 | 4人チーム(1人1枚のカードを担当) |
| 目安時間 | 30〜40分(要リハーサル) |
| 答え | `20171226`(西暦8桁) |
| 一言でいうと | 4人が別々の迷路を解き、**全員が通ったマスだけ**を読むと、最後の問いが現れる謎 |

**ポイント**:各自の迷路を解いただけでは意味のある文章になりません。「表のサービスは別々でも、裏側に共通の基盤がある」というテーマが、「4本の経路に共通するマスを探す」という解法になっています。

## 2. 全体の流れ

```text
歴史順に並べる → 自分のカードの番号を知る → 迷路を解く(例:Ⅰから入ってⅡへ抜ける)
→ 通ったマスに自分の記号を書く → 4人の記号が揃うマスを探す
→ 読み順に読む → 最後の問い → 答え
```

## 3. 配布物

| 配布物 | 枚数 | 内容 |
|---|---|---|
| サービスカード | 4枚 | 表:サービスの題材 / 裏:迷路 |
| 沿革の断片 | 3〜4枚 | 「AはBより前」のような前後関係が分かる資料 |
| 共通の文字盤 | 1枚 | 7×7マスの単語表(全員で共有) |
| 筆記具 | 4種 | 各自の記号(○△□☆など)。色だけに頼らない |
| 回答欄 | 1枚 | 「西暦8桁の数字」と書いておく |
| ヒントカード | 4〜5枚 | 段階式(9章) |

カードの題材は4枚とも過去の出来事として扱います。

- ① STREAMの現物取引サービス
- ② セゾンポケット
- ③ Wealth Wing
- ④ セゾン投信の移管案件

カード裏の指示文:

> この記録が歴史の何番目か。その番号のゲートから入り、次の番号のゲートへ抜けよ。(Ⅴ=現在)

## 4. 最初のメッセージの読み解き

| 文 | 意味 | 解く側が気づくこと |
|---|---|---|
| 4つのサービスへの経路が断絶した。 | 迷路が4つある | 4枚のカードの裏が迷路 |
| それぞれの経路を復旧せよ。 | 各自が迷路を解く | 1人1枚、入口から出口まで進む |
| 未来への問いは、すべてのサービスを支えている場所に残した。 | **4本の経路すべてが通るマス**に問いがある | 全員の経路を比べる必要がある |

## 5. 解き方の詳細

### 5-1. 歴史を復元して、カードの番号を決める

沿革の断片から4件を古い順に並べます。

```text
STREAM(Ⅰ) → セゾンポケット(Ⅱ) → Wealth Wing(Ⅲ) → セゾン投信の移管(Ⅳ) → 現在(Ⅴ)
```

### 5-2. 迷路を解く(入口と出口はリレー)

各カードの迷路は、**自分の番号のゲートから入り、次の番号のゲートへ抜けます**。

| カード | 入口 → 出口 |
|---|---|
| ① STREAM | Ⅰ → Ⅱ |
| ② セゾンポケット | Ⅱ → Ⅲ |
| ③ Wealth Wing | Ⅲ → Ⅳ |
| ④ セゾン投信の移管 | Ⅳ → Ⅴ |

- 迷路は4枚とも同じ7×7マスで、壁の配置だけが違います。
- 5つのゲート(Ⅰ〜Ⅴ)は、4枚とも同じ位置に印刷します。
- 完全迷路なので、どのゲートの組み合わせでも道は1本だけ見つかります。順番を間違えても解けてしまいますが、後で共通マスが5つ揃わなくなります。

### 5-3. 文字盤に記録する

全員が自分の記号で、**通ったマスすべて**(入口と出口のマスも含む)に印をつけます。この時点では、自分の経路上の単語を読んでも意味は通りません。

### 5-4. 全員が通ったマスを読む

4人全員の記号が揃ったマスが、ちょうど**5つ**あります。文字盤の**左上から右下へ(上の行から、左から右へ)**読むと、次の語が並びます。

```text
スマ / プラ / 証券 / 登録 / 日   →   「スマプラ 証券 登録日」
```

これが最後の問いです。回答欄には**西暦8桁**で答えを書きます。

## 10. 運営メモ

### つまずきと対処

| 症状 | 考えられる原因 | 対処 |
|---|---|---|
| 迷路の出口が分からない | 歴史順が未確定 | 沿革の断片を整理させる(ヒント1・2) |
| 迷路は解けたが、共通マスが5つにならない | 誰かのゲート番号か経路がずれている | ヒント5。各自の経路を見直させる |
| 5マス見つかったが読めない | 読み順の誤り | 「上の行から、左から右へ」と伝える |
| 問いは読めたが答えに辿り着けない | 調べ方が分からない | 検索可否を事前に決めておき、可なら出典の公式発表を示す |

### 難易度の調整

- **易しくする**:最初のヒントを先に渡す。文字盤の太字を薄く印刷する。
- **難しくする**:沿革の断片を相対表現(「〜の翌年」など)にして、整理しないと順番が決まらないようにする。迷路は複雑にしすぎず、時間を使う中心を「共通部分への気づき」に置く。

### 半透明で重ねるオプション

台紙で解いて、自分たちで重なりを見つける形で十分です。重ねたい場合は、各自が自分の経路だけをトレーシングペーパーに太線で写し、4枚を重ねて光に透かします。濃く見えるマスが共通マスです。

### 迷路を作り直すときのルール

- 壁は「すべてのマスが1本の木でつながる」形にする(閉じた輪を作らない)。
- 各迷路の正解ルートが、5つの共通マスをすべて通るようにする。
- どのマスも、4枚すべてには現れないようにする(5つの共通マスを除く)。
